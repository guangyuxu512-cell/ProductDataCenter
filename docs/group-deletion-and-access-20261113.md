# 分组删除和旧客户端入口

分组删除确认弹窗点击后发生前端异常，删除请求未发出。改用现有 `AppDialog` 处理确认：取消不发送请求，失败时保留弹窗并允许重试，成功后刷新列表。后端分组删除仍保留商品并将其归入未分组。

旧桌面客户端默认打开 NAS 局域网入口 `http://192.168.0.102:3612/`；该入口通过原有私网代理连接服务器商品 API，与服务器公网入口读取同一 PostgreSQL。局域网入口对受信网段免登录，公网入口使用原网页登录认证。两个入口各自提供网页静态文件，发布前需分别核对版本。

回归覆盖确认删除、取消、请求失败后重试，以及现有商品列表和分组操作。
