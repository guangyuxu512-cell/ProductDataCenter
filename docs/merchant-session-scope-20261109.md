# 商品库商家会话用途接入

- 基线：ProductDataCenter `80392f12575db2a32d22e2a07b7e2668dbc7b37a`；该 Git 基线不代表 NAS 当前运行镜像。
- 商品库向中控申请 merchant 用途；只有得到 `X-Merchant-Identity-Verified: 1` 才使用返回的会话。明确的身份未确认 409 可换下一家已授权店，其他连接、授权或平台异常保留各自失败含义；平台 10008 仍按既有有限换店规则，不推断一定需要重新登录。
- 商品库读取带 `X-Session-Metadata-Version: 1` 的授权店铺版本，只命中此前通过同店验证并成功取数的 `merchant-v1:<店铺>:<Session版本>` 缓存。旧缓存保留但不命中；刷新只影响当前店铺版本。缓存是历史结果，不证明平台此刻仍在线。
- 缓存命中需一次中控授权/版本读取，不请求平台；冷查询还需一次 merchant Session 核验及实际类目请求。明确身份未确认对同店同版本限 30 秒进程内去重，不保存凭据；会话版本变化立即失效。正常成功的不同冷类目不跨请求复用会话，仍受每店并发上限约束。中控 Set-Cookie 更新也可能增加版本，使后续缓存再次变冷。
- 自动预检沿用原有退避重试；RPA 显式要求类目名称时，无法确认会返回 `RPA_CATEGORY_UNAVAILABLE`，普通 UU 读取不受影响。
- 上线须由负责人核验 NAS 实际镜像及与 Git 基线的差异。商品库应先具备缺验证头即拒绝的能力，再配套中控发布；中间阶段类目查询可能暂不可用。不得把旧版商品库回滚当成仍有该验证保护。最终须在授权的真实店铺、空缓存、正式接口验证，不能以本地替身测试代替。
- 本分支不请求真实平台、不修改 NAS 或生产，不包含数据库迁移。LFS 安装包仅以 Git 指针检出，本次未验证安装包。
