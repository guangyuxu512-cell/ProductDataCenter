# 商品库入口图片上传 500 修复

2026-11-11，服务器商品库 HTTPS 入口对约 11–30 KB 的图片上传返回 nginx HTML 500，小图片仍能上传。商品库 API 没有收到失败请求：入口 nginx 错误日志显示请求体临时文件的路径写入遭拒。两个独立 nginx 进程使用同一套默认临时目录、运行账户不同，重载时目录所属用户也可能改变，导致故障间歇出现。

服务器商品库网关已为请求体和代理等五类 nginx 临时文件设置独立目录，且目录只允许其 worker 用户访问；其他 nginx 原有临时目录的所属用户已恢复。网关配置通过语法检查并热重载，原配置留有备份；没有修改生产 Compose、数据库或商品。网关再次重载后，两套 nginx 的临时目录权限保持独立。

生产实测：合成的 800×800 JPEG（258,092 字节）和 WebP（261,272 字节）上传均返回 201，公网地址返回 200 且字节一致，NAS 商品库图片目录中均确认内容一致。再次重载后，174,366 字节 WebP 的上传、公网读回和 NAS 文件内容再次核对通过。既有 WebP 图片仍返回 200；这些是合成测试图片，并非用户报告中未随请求提供的原文件。

## 部署要求

`deploy/nginx.server-ingress.conf.template` 应仅用于商品库独立 nginx 进程的 `http` 上下文。先创建 `/var/lib/product-data-center`（root 所有、0755），并建立 `nginx-client-body`、`nginx-proxy`、`nginx-fastcgi`、`nginx-uwsgi`、`nginx-scgi` 五个子目录，目录归实际 nginx worker 用户及组所有、权限 0700。不要复用其他 nginx 的临时目录，也不要把这些 http 级配置直接套入其他站点共用的 nginx 进程。

部署时先验证模板、目录及 nginx 语法，再热重载指定的商品库网关；实测超过请求缓冲区大小的 JPEG/WebP 上传、返回 URL 和 NAS 文件，并检查现有网页、API 与图片读取。`scripts/test_server_ingress.py` 使用隔离端口和无写权限的默认临时目录，覆盖认证、路由及较大上传请求的转发。
