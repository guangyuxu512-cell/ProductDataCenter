# 商品图片预览下载

商品列表缩略图、编辑窗口中的主图、详情图、SKU 图和规格值图片共用图片预览下载行为。点击预览工具栏中的下载图标，读取当前预览的原图并保存为图片文件；不更改商品、草稿或图片排序。图片不可读取、下载失败或来源未允许浏览器跨域读取时显示失败提示，不离开当前商品。单件和批量商品数据包仍使用原有 ZIP 导出流程。

商品库自行上传的图片原本已允许无凭据读取；图片响应增加跨域读取头，使局域网页面可以下载已公开的图片，不增加管理接口或数据库的公网权限。第三方图片的读取仍受来源服务和网络限制；没有开放跨域读取的来源不能保证使用此按钮下载，禁止伪装成成功。

下载时重新请求原图，以避免本机先前缓存了不含跨域头的旧图片响应；不改变商品中保存的图片地址。

## 检查与状态

- 检查原预览组件发现默认下载操作只打开图片地址；桌面客户端禁止外域导航，因此可能点击后没有反应。该行为同时影响列表和商品编辑窗口，不仅是规格图。
- 北京时间 2026-11-09 对现有商品只读采样：抖音和拼多多的主图、详情图、SKU 图来源均返回图片且允许当前局域网页面跨域读取。独立浏览器对各一张真实抖音、拼多多商品主图执行读取和下载，下载字节数与读取字节数一致；不能据此保证所有第三方地址均支持。
- 商品库自有公网图片当前可直接读取，但现有响应未提供允许局域网页面读取的跨域头；此修复在隔离后端补齐，正式服务的头部尚待发布后复核。
- 单件和两件批量的正式数据包导出接口只读验证 HTTP 200，返回的 ZIP 均可解析；隔离浏览器同时验证点击导出产生文件。
- 隔离浏览器验证列表、主图、详情图、SKU 图及规格值图片下载对应原始字节；失败时保留预览，ESC 与未保存草稿不丢失。前端单元 44 项、浏览器全量 41 项通过；随后新增旧缓存兼容验证，下载专项 4 项再次通过。独立 Electron 44 客户端使用模拟商品和独立资料目录，实际捕获并核对图片和数据包下载，未触碰用户客户端资料。
- 后端图片专项 4 项、Windows 环境内其余 156 项非集成测试、共享源码检查通过；一个符号链接安全测试因 Windows 缺少创建符号链接权限未通过，改由 Linux CI 验证。PostgreSQL 集成测试和容器检查仍以 CI 为准。
- 上述检查起初针对候选实现。图片专项版本 `22414b60e1b45effc69be0ecf36b1b411a8ff8ab` 后续已完成 NAS 隔离验证和正式部署，见[图片更换发布记录](image-replacement-20261109.md#2026-11-09-正式发布与核验)。商品库类目映射仍有独立的登录状态验收门禁。
