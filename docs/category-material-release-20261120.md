# 类目补查与复合材质发布记录

2026-11-20 发布商品库代码 `48999d27571ec7c137e104981e3c91c7819bb8a2`。正式 API 和 Web 均运行对应镜像，PostgreSQL 与 NAS 图片存储未切换。发布前另行备份数据库，并在恢复的隔离库检查商品列表、商品编辑读取和 RPA 数据包读取；隔离副本及正式切换前后均为 720 件商品。

## 已核验

- 正式网页针对真实商品检查：`居家日用 → 其他家居日用` 原有逐级列表返回七项，不含热水袋；在第三级输入“热水袋”并使用“搜索平台类目”，可看到并选择平台返回的 `1000011128`。正式属性接口返回九项，网页草稿可看到包含三段输入的“商品尺寸”。验证草稿没有保存到商品。
- 正式网页只读检查 `服装 → 服装配饰 → 其他服饰配件` 的既有商品，`聚酯纤维100%` 显示为可展开的材质选项和数值 `100`、单位 `%`。真实规则的有选项及无选项两种情况，均在隔离界面测试中覆盖自定义输入、保存、重新打开和删除，未使用用户商品执行写入测试。
- GitHub 的后端（含独立 PostgreSQL 集成测试）、前端、容器和 Windows 检查通过。本机完整界面回归 60 项中，主题切换一项首次超时，单独重跑通过。发布后正式商品列表、编辑读取、RPA 读取及网页文件检查通过。

## 尚未完成

- 搜索是逐级列表缺项时的补查方式，不代表已经取得平台完整类目树，也不保证自动推荐一定有结果；历史商品不会自动改类目。
- Worker 返回的属性仍只包含投影后的部分平台数据，非空 `unit_rules` 等规则不完整；“水洗标/吊牌图”的真实数据结构和写入方式尚未确认，不能上传、保存或据此声称预检完整。已交中控/Worker 负责人核对。
- 部分自定义材质的旧文本无法唯一拆分名称和数字时会保留原文，预检不会将不确定的规则当作通过；例如未能用真实选项消除歧义的 `自定义99%`。尚未验证这类值的分项回填，也未宣称所有服装三级类目均已适配。
