# SKU 表格分组与桌面输入修复

- 桌面端新增规格类型和规格值使用商品库内的输入弹窗，复用原有草稿、SKU 组合及保存流程；取消不修改商品。
- 对规格 ID 可以完整对应的抖音商品，SKU 表格按编辑界面的规格顺序分组，合并相邻同一规格 ID 的首列；每行价格、库存、SKU ID 和规格图片仍绑定原 SKU。无法可靠匹配的来源保持原顺序，不猜测组合。
- 排序仅作用于显示，不重排商品包或数据库记录。预检价格问题按 SKU ID 定位，显示序号随表格顺序更新。
- 回归覆盖乱序的两种颜色、六个尺码、12 个 SKU；检查合并单元格、每行价格库存、预检定位和仅修改目标 SKU 的保存请求。另在 Electron 44 桌面环境使用隔离模拟接口验证新增规格值并提交。
- 正式发布需通过仓库 CI，备份共享 PostgreSQL 并恢复到隔离库，验证 SKU 修改与数据包、RPA 读回；切换前后检查实际镜像。CI 或镜像构建本身不代表生产已上线。
