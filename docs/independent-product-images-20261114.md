# 商品库图片域名与存量数据统一

商品库新上传图片返回配置的 HTTPS 商品库域名；NAS 仍保存图片文件，服务器通过图片专用私网服务传输。NAS 内部响应若使用明确配置的原地址，商品库只接受符合本服务 UUID 文件格式的响应，并对外返回商品库域名，不访问中控图片接口。

商品列表、详情、编辑、导出及 RPA 数据包使用相同商品库图片域名；旧地址只对配置过的本服务图片路径进行转换，不改来源平台图片。保存旧编辑草稿时也会转换本服务图片地址。

历史数据通过 `python -m app.modules.product_images.migrate_urls` 一次性统一：默认 dry-run，显式 `--apply` 才在同一事务内更新商品包、图片及 SKU 图片地址，重算商品包摘要。更新商品包沿用现有数据库预检触发器。执行前必须备份并在恢复的隔离副本演练；失败时事务回滚，不删除图片或商品。只允许明确列出的旧根地址，不对来源 CDN 做替换。

上线前分别验证浏览器上传、AI 上传、保存及读回、导出和 RPA 数据包；CI 或镜像生成不等于生产部署。
