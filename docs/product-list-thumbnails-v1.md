# 商品列表小图

- 继续使用中控来源的 `ProductImage`，列表和详情导航复用它，布局、主题及交互不变。
- 只对不带参数、没有签名的 `p3-item.ecombdimg.com` 和 `p26-item.ecombdimg.com` 已验证 WebP 模板派生 144px 图片；原本小于等于 144px 的抖音地址保持原样。对 `img.pddpic.com` 和 `commimg.pddpic.com` 的无参数 JPEG、PNG、WebP 地址派生 CDN 小图；其他来源、格式和带参数地址一律使用原地址。
- 在滚动区域中，仅为进入视口的图片设置来源；浏览器不支持 IntersectionObserver 时使用组件的原生懒加载。小图失败后只回退一次原图，原图失败保留逐图重试；放大预览始终使用原地址。
- 不代理、下载或存储图片，不改变原始数据、UU、数据库、商品接口或 RPA 凭据。

## 验证边界

前端端到端测试使用可控的隔离图片服务替身，验证加载顺序、请求地址、回退、重试、原图预览和既有业务操作；不等同真实 CDN 或用户网络的速度承诺。实测生产列表中拼多多两个域名的 3 个 JPEG/PNG 样本均返回 144px 图片；这不是对所有资源的保证，发生错误时回退原图。

`scripts/benchmark-product-list.py` 只允许访问固定名称的空隔离库；基于采集项目 0001–0008 结构生成 30 万商品、120 万 SKU、120 万图片记录，预热后测量本项目 FastAPI 的本地 HTTP 耗时、单请求和 5 并发。其独立 GitHub Actions 作业输出原始结果。数据、硬件及网络均是合成环境，不代表 NAS、真实商品分布、真实 CDN 或浏览器整页加载成绩。
