# 服务器商品库与 NAS 图片上传准备

日期：2026-11-10。此分支基于 NAS 已运行的 `22414b60e1b45effc69be0ecf36b1b411a8ff8ab`，准备服务器商品库把图片上传到 NAS；本文件和代码均不代表正式部署。

## 方案

- 商品库对客户端保留原有 `POST /api/v1/product-images`。后端开启远端模式时，校验图片类型和大小后通过私网把内容发送给 NAS 图片服务；只有 NAS 返回有效的既有公网图片 URL 才返回成功。只存在上传期间的临时文件，持久图片由 NAS 保存。
- NAS 使用同一商品库 API 镜像运行 `app.image_storage:app`，仅注册健康检查、图片上传和图片读取，不注册商品、预检或数据库接口。上传使用单独的图片服务凭据；不把 NAS 商品管理凭据交给云端。
- 远端模式由 `BACKEND_IMAGE_REMOTE_UPLOAD_ORIGIN` 和 `BACKEND_IMAGE_REMOTE_UPLOAD_TOKEN_FILE` 同时启用。配置缺失或 NAS 不可用时返回失败，不回退到服务器持久目录，也不伪造 URL。
- 现有图片 URL、平台源图及数据包结构不因该功能改写。NAS 服务和服务器需配置同一个已有公网图片根地址；`/rpa/v1/product-images/` 的公网入口仍需在切换时确认转发到 NAS 图片服务或共享目录。
- `deploy/compose.nas-image-storage.yaml` 和 `deploy/compose.remote-image-upload.yaml` 是准备模板，不会自行创建 NAS 图片目录或应用任何生产配置。NAS 目录沿用现有商品库目录；测试必须先使用隔离目录和单独凭据。
- 服务器向 NAS 使用 HTTPS，或通过受限私网/Tailnet IPv4 的 HTTP；后者依赖私网链路本身提供加密。远端地址不得包含凭据、路径、查询参数或重定向；不读取系统 HTTP 代理配置。

## 已完成的隔离验证

- 本机自动化覆盖原 NAS 本地上传、服务器转发、图片服务独立鉴权、图片类型与大小校验、禁止公网明文上游、上游重定向/认证失败/伪造 URL 和异常响应。
- 两个独立 HTTP 进程演练：模拟云端后端上传后，图片只写入模拟 NAS 目录并可原样读取；模拟 NAS 停止后，上传返回失败。测试使用合成图片和临时目录，不访问生产数据库或图片。
- 在服务器使用当前生产镜像及本分支候选代码构建隔离测试镜像，在无外部网络的两个容器中运行实际云端 API 和实际 `app.image_storage`。上传及图片原样读回通过；图片服务没有商品 API，图片服务凭据不能访问云端管理接口；关闭图片服务后上传返回 503。图片服务使用只读根文件系统及独立测试目录。
- 在服务器启动候选云端上传代码，通过 Tailnet 请求 NAS 上的临时模拟图片服务：一张合成 PNG 写入 NAS 专用隔离目录，返回 HTTP 201 和预期地址，文件字节匹配；停止模拟服务后再上传得到 HTTP 503。服务均已停止，未修改正式图片或商品。此项使用 NAS 模拟服务，不代表实际 `app.image_storage` 已在 NAS 部署或验收。
- 真实服务器通过 Tailnet 读取现有 NAS 图片成功；一次无数据 TCP/HTTP 探针验证了服务器可经 NAS Tailnet 地址访问 NAS 的临时回环监听。两个 Compose 模板使用模拟参数通过服务器 `docker compose config --quiet` 解析检查。
- Windows 后端常规测试在启用 UTF-8 后，除系统不允许创建符号链接的既有测试外均通过；该测试的路径逃逸断言另在服务器 Linux 容器通过。真实 NAS 文件服务、正式 PostgreSQL 迁移及 CI 仍待验证。
- Windows 后端 PostgreSQL 集成测试连接服务器上的独立空测试库并经临时 SSH 转发执行：25 项通过。测试使用合成凭据，结束后测试库及转发已停止；没有连接正式数据库。
- 实际 NAS 图片容器首次启动未通过：该 NAS 内核不支持 Docker 的 CPU CFS 限额。已准备去除该测试参数的重试，真实 NAS 图片服务验收仍待完成；该故障不代表正式服务发生变更。
- 去除测试容器的 CPU CFS 限额后，在 NAS 独立目录中启动实际 `app.image_storage`（当前正式 API 镜像加候选源码只读挂载）；服务器运行候选商品库 API，通过 Tailnet 上传合成 PNG，返回 HTTP 201，NAS 上的文件摘要与原图一致，直接读回为 HTTP 200、`image/png`。未授权上传返回 401，图片服务的商品接口返回 404，图片服务凭据不能访问云端管理接口。停止 NAS 测试服务后，云端上传返回 503；两个测试容器均已停止。此项采用虚构的 `https://images.example.test` 地址，不代表真实公网 URL 和外地 RPA 下载已经验收，也未挂载正式图片目录。
- 新增独立 HTTPS 入口的 nginx 配置候选，并在服务器本机使用临时证书、模拟 Web/API 和模拟凭据验证：无凭据及错误凭据被拒绝；网页 Basic 认证通过后交给 Web；管理 Bearer 凭据交给后端验证；RPA 凭据和公开图片路径不注入管理凭据。测试未修改现有 nginx 或防火墙，也未证明公网入口已开通。

## 上线前必须完成

- 在正式切换前验证真实公网 URL、重启、外地 RPA 下载以及正式图片目录权限；确认现有公网图片入口转发和相关服务恢复流程。
- 配置和验收 NAS 采集容器到服务器 PostgreSQL 的可靠私网连接；服务器现有中控 API 与商品库 API 路径冲突，需要独立入口和授权。
- 正式入口必须使用有效证书和实际授权配置，验证浏览器、Bearer 客户端、RPA 与中控原入口；不得直接暴露未加认证的 NAS 局域网代理。服务器现有防火墙默认拒绝入站，额外端口需在部署时核验服务器和云防火墙规则。
- 按现有发布流程完成 CI、真实数据库新备份和隔离恢复，迁移缓存与数据库角色；验证采集、保存后预检、桌面客户端和 RPA。切换及回滚不得删除旧数据库、卷或图片。
- 本机和模拟进程测试不能代替真实 NAS、服务器、手机采集或外部 RPA 验收。类目查询既有问题与本上传适配分别验证。
