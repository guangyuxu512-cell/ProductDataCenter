# 商品图片更换

编辑商品时，主图和详情图支持本地替换或输入图片链接，规格图也可使用这两种方式。更换先作用于草稿，点击保存后才写入商品包；关闭未保存的草稿不修改商品。图片链接使用应用内输入框，兼容商品库桌面客户端。图片下载见 [预览下载](image-preview-download-20261109.md)。

抖音和手动商品沿用现有规格图保存逻辑。对已转换的拼多多 UU，只有规格值、SKU 数据包和 PostgreSQL 记录能够唯一对应时才开放第一组规格图更换；其他拼多多原始包或对应不完整的商品禁止更换规格图。保存只修改对应规格图片，不改其他规格、SKU 和没有对应规格的图片记录，也不删除图片文件。拼多多规格结构及 SKU 信息编辑仍不在支持范围。

## 隔离检查与发布状态

- 已复现旧桌面客户端无法使用浏览器原生图片链接输入框，原有规格图更换和主图、详情图添加链接均受影响。已复现原拼多多商品规格图在界面提供更换入口，但保存时后端拒绝。
- 只读采样 12 件实际拼多多商品：数据包的规格与 SKU 映射、编辑快照与数据库 SKU 标识均能对应；使用数据包副本在内存中验证规格图更换，不写入生产商品。不能据此推断其他所有商品的格式均相同。
- 隔离浏览器覆盖抖音与拼多多的主图链接更换、详情图本地替换、规格图链接更换、保存和重新打开；独立 Electron 客户端与单独资料目录覆盖主图本地替换、详情图及规格图链接更换。测试使用模拟接口和商品。
- PostgreSQL 测试使用单独测试库检查数据包、图片记录和 RPA 读回；仓库 CI 是集成检查结果的依据。正式部署前还需按既有流程验证候选镜像与隔离数据。
- 本记录描述候选代码，不代表已部署。类目映射的既有发布门禁须独立完成，不能因图片测试通过而视为通过。
