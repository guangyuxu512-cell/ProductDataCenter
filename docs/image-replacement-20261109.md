# 商品图片更换

编辑商品时，主图和详情图支持本地替换或输入图片链接，规格图也可使用这两种方式。更换先作用于草稿，点击保存后才写入商品包；关闭未保存的草稿不修改商品。图片链接使用应用内输入框，兼容商品库桌面客户端。图片下载见 [预览下载](image-preview-download-20261109.md)。

抖音和手动商品沿用现有规格图保存逻辑。对已转换的拼多多 UU，只有规格值、SKU 数据包和 PostgreSQL 记录能够唯一对应时才开放第一组规格图更换；其他拼多多原始包或对应不完整的商品禁止更换规格图。保存只修改对应规格图片，不改其他规格、SKU 和没有对应规格的图片记录，也不删除图片文件。拼多多规格结构及 SKU 信息编辑仍不在支持范围。
