# 商品详情布局 V1

商品详情工作区调整为左侧商品范围、右侧四个页签：基本信息、图文信息、商品属性、规格与 SKU。左右区域独立滚动，切换商品时保持当前页签，旧数据加载期间不可操作。布局沿用现有中控组件、主题和缩略图能力；图片放大仍读取原图。

本次为独立的**只读页面**：读取已部署的商品详情接口，不依赖编辑草稿、店铺 Session、签名、预检或数据库迁移。来源店铺和来源类目按现有采集字段显示，不冒充预检店铺或抖店目标类目。现有详情接口未提供的属性、库存、商家编码和 SKU 状态保持空值，不猜测组合或状态；保存、手动创建及预检未接入，不显示可执行入口。

移动分组、商品数据包导出、分页、搜索和图片查看沿用既有接口和行为；仅将用户可见的 UU 导出名称改为“商品数据包”。未改 RPA 接口、原始数据包格式、数据库查询、后端或采集流程。移动分组仍由既有配置控制，未启用时禁止写入。

发布按既有流程先备份、隔离校验并确保 RPA 无冲突，再只更新 Web 镜像；保留原 Web 镜像和配置便于回滚。目标生产数据库为手机采集系统既有数据库，禁止运行编辑草稿提案 DDL。此页面不代表商品编辑、店铺选择、平台预检或改后数据包已经可用。
