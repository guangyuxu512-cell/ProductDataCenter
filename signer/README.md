# 商品云库独立签名器（候选）

商品云库在 NAS 运行独立签名实例；中控原签名实例和 Session 保持原样。签名器不保存店铺
Session，也不负责商品预检或向抖店发送请求。商品云库接入和真实店铺预检仍需单独完成。

## 来源与边界

`server.js`、`sign_once.js` 和 `vendor/a_bogus.js` 源自本用户 AIdashboard
`877f13170fd88e811ce0be17d818849b98f6fec2` 的 `backend/douyin-signer`。
保留每次签名独立子进程；此处仅为独立部署增加密钥文件、绑定地址和密钥格式校验。
原代码中的私有平台签名算法和入参不得作为永久稳定协议；升级需重新验证目标平台接口。

`deploy/compose.signer.yaml` 是独立可选部署文件：镜像固定到经验证的 SHA，接入已有商品云库
Docker 网络，不映射 NAS 主机端口。密钥从受保护的文件读取，必须为 32–256 个英文字母、数字、
下划线或短横线；文件须能被
容器的 `node` 用户读取。不要把密钥或店铺 Session 写入 Git、应用日志、网页或示例文件。
该方案不改现有商品 API、RPA API、手机采集或数据库，不修改中控签名实例。

## 验证与状态

`node --test signer/tests/server.test.cjs` 使用虚构会话、关闭签名子进程网络并行测试 25 次。
CI 另在禁用外网的容器验证构建产物、生成单独镜像包。模拟签名成功不能证明真实店铺或类目
接口请求成功；在用户现有 NAS 网络、内存、鉴权及目标接口完成联调前，不应启用到生产流量。
